Prueba Especial y Vueltas

Un circuito tiene una sola prueba especial que se corre en varias vueltas sobre el mismo trazado (el punto de inicio y el de meta son el mismo lugar).

Puntos intermedios del recorrido donde el operador podrá registrar la hora de paso de cada vehículo, para verificar que completó el trazado en cada vuelta.

Si hay muchos pilotos no todos pueden salir juntos a pista por seguridad: divídelos en mangas (ej. "Manga 1", "Manga 2") que saldrán una a la vez. Al inscribir a cada piloto elegirás a qué manga pertenece.

Carga Masiva de Resultados

Sube de una vez los datos de inscripción y tiempos de una Prueba Especial completa, usando la plantilla Excel. Ideal para cargar rápido la hoja oficial de resultados.

1. Elige el destino

Borra de una sola vez todos los tiempos cargados (por Excel o a mano) para la plantilla elegida arriba. Los pilotos inscritos no se borran, solo sus tiempos en esta PE/vuelta.

2. Descarga la plantilla y complétala

La plantilla trae de referencia las clases habilitadas para este rally, la distancia y la hora prevista. Respeta las columnas: Nº y Psto. son solo de referencia (no se usan), el sistema calcula el puesto y el tiempo neto solo a partir de Hr. Salida, Hr. Paso y Penalización. PILOTO / NAVEGANTE va como "Nombre Completo / Nombre Completo". Hr. Salida es solo hh:mm; en Hr. Paso también puedes escribir NO LARGO o ABANDONO si el piloto no completó el tramo. Una fila completamente vacía se ignora (sirve para separar categorías). En circuitos, si un piloto compite en varias clases con el mismo auto, repite su fila completa una vez por cada clase (mismo Nº, misma hora, cambiando solo la CLASE) — no hace falta ningún símbolo especial.

Elige primero el Rally y la Prueba Especial de arriba.

3. Sube el archivo lleno

4. Revisa antes de confirmar

¿Cómo obtener un enlace público de Google Drive?

  1. Sube la imagen o el PDF a tu Google Drive (drive.google.com).
  2. Clic derecho sobre el archivo → Compartir.
  3. En "Acceso general" cambia a "Cualquier persona con el enlace", rol Lector.
  4. Solo para PDF (RPP): abre el ícono ⚙️ dentro del cuadro de compartir y desmarca "Los lectores pueden descargar, imprimir y copiar" — así queda protegido contra descarga.
  5. Clic en "Copiar enlace" y pégalo en el formulario correspondiente aquí abajo.

¿Cómo obtener un enlace público de Google Drive?
